- `text_v3::encode(&PreparedAction) -> Result<TextKey, TextError>` encodes one validated action/variant; `encode_prepared(&Prepared)` encodes the complete original chunk AST with original action constraints, retaining cross-action connectives. Fan-out alternatives are separately encoded actions, not silently included in the original chunk key. Original ceiling is 2000 Unicode characters; spans remain UTF-8 bytes.
- `TextKey` is privately constructed, exposes `pattern_key()`, `resolution()`, `token_count()`, `transform()`, `preimage()`. `Resolution::{Low,Medium,High}` uses actual AST lexical count at <=6/<=16/else, excluding punctuation; explicit connective/negation nodes add one. Low uses sorted unique typed lexical leaves, numeric captures become `#`, quotes remain distinguished, control topology/safety constraints remain. Medium retains ordered role-labelled leaves, canonical numbers/operators, controls/guards. Low/medium omit punctuation; high retains complete typed AST including punctuation, unresolved SPO and canonical captures. Every field/tag uses u64 big-endian byte-length framing; lists have u64 element counts. Preimage is LP(transform)||LP(class)||LP(text); SHA256 supplies all 32 digest bytes to `identity::PatternKey { encoder_version: text-v3, modality: text, resolution, digest }`. No source spans, host IDs, rule refs or draw metadata enter it.
- `scanner_v3::scan(&PreparedAction,&PreparedAction)` and explicit `scan_modality` return `Evidence { version: text-scanner-v3, components:[Component;4], totals, left_constraints, right_constraints }`. Each component exposes weight, exact S/D fractions, spans and reason. Lexical components traverse every immutable action-AST leaf once, including retained conditional antecedent, excluding punctuation; quotes remain opaque. Body SPO and numeric/operator captures remain producer features: no antecedent roles/numbers/truth are invented. No whole-chunk scanner is supplied. No key or candidate resolution is accepted by scan.
- Weights are 40 multiset lemma Jaccard, 20 ordered-bigram multiset Jaccard, 20 equal-resolved SPO thirds, 20 all-or-nothing exact nonempty canonical operand tuple plus ordered operators. Explicit negation conflict zeros only the role component with `NegationConflict`; missing components contribute 0S/fullD. S/D sum to 100 for scanner evidence. Identical unresolved plain two-token text scores 20; a single plain opaque token scores -20, intentionally unspecial-cased. Scores are not probabilities.
- Shared public `Rational::new(i128,i128)` requires positive denominator and gcd reduces; getters, checked add/subtract and display-only truncation toward zero are exposed. `reduce_totals(S,D)` retains exact unclamped totals, performs one checked difference, then clamps that rational to [-100,100]. Overflow and unsupported modality are explicit errors. No float scanner math or intermediate rounding.
- `scanner_v3::routes::RouteIndex::new(population, scopes, registry)` binds explicit host population/scopes/current immutable registry. `register(table,current_registry,Vec<RouteRule>)` validates complete batch before publishing. Typed `GrammarAtom::{Literal,Quoted,Number,Operator}` consumes producer tokens; wildcard prefix/contains rules require explicit `SimilarityBypass::{RequireFullScan,Declared}`; separate automaton rules name registered Tape handler/program/expected bytes. No rule depends on text-key coincidence.
- Pure joining `routes::candidates(table,index,population,scope,prepared,current_registry,capabilities,RouteBudget)` calls `HybridTable::find_all` for each action structural key, then explicit routes. Result is complete or error, deduplicated only by concrete EntryRef. Deterministic order: clauses/variants, structural refs in table order, route IDs sorted, rule refs supplied order. Every origin, fan-out, capture, source span, constraint and bypass declaration survives. Target ActionAst alternatives retain inhibition/weight. Retrieval never forces voting, authorization or admission.

## Bounded route interpretation and rulings

Index limits: 4096 rules, 4096 aggregate target refs, 64 refs/rule, 64 prefixless wildcard rules (contains or empty prefix), 64 automata; grammar <=256 atoms and <=2000 aggregate pattern characters; literal/program <=2000 characters/bytes respectively, expected output <=1024 bytes. Prefix index uses first UTF-8 byte, then exact prefix check; contains is an explicit bounded bucket and returns every nonoverlapping literal occurrence, preserving literal/before/after captures. Registration checks referenced entries/population/scopes, duplicates, bounds and registry before mutation; query rechecks current refs/population/registry.

Parent explicitly accepted the typed Tape adapter: construct a quote-safe literal producer invocation from program and preserved `action.original()` via JSON string encoding, then reuse reviewed `compile` + `execute_for_action`. Actual UTF-8 original bytes reach Tape. Exact byte-vector output determines a match. There is no new language parser, dynamic binder or script import registration. An inhibited/unresolved action yields an explicitly unexecuted `AutomatonStatus::Blocked` origin, never a successful match. Unknown conditions/negation remain unresolved/inhibited through every route.

Query budgets are aggregate logical reservations, not timing measurements: work 1..=1,000,000 (default ceiling), output 1..=65536, origins 1..=65536, per-automaton Tape steps 1..=10000. Each Tape invocation reserves program/input length plus its full Tape-step allowance plus 500 call units, and 1024 output bytes before executing; multiple automata cannot reset that query allowance. Wildcard matching reserves comparison and substring-copy work before allocating captures. Exhaustion/runaway/stale registry fails without returning partial candidates. These conservative reservations can refuse a query whose actual Tape work/output would have been smaller. This is not the global 1000 scan-permit scheduler.

Parent also ruled that action-scoped lexical scanning must include retained conditional antecedent AST leaves once; a real RED/GREEN regression pins different `if rain then hello` / `if sun then hello` lexical evidence while leaving absent SPO/numeric components absent. Conditional constraints remain separate evidence, with no invented penalty or truth resolution. Cost if local adapter/scanner choices prove wrong: revise the profile/version fixtures before runtime registration.
