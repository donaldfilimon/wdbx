## Public immutable API for downstream tasks

`language_v3::prepare(Input { id, text }, &ContextSnapshot, &UtilityTables, Budget, &mut dyn DrawSource) -> Result<Prepared, LanguageError>`. All fields of Prepared and its validated result members are private. Input/configuration snapshot fields are public caller inputs; their mutation cannot change a constructed UtilityTables or Prepared result. FixedDraw is a deterministic supplied-draw helper with an exact [0,1) mapping; no RNG/time/I/O occurs.

Utility snapshot construction: `UtilityTables::new(population, version, Vec<UtilitySnapshot>)`. `UtilityKind::ALL` names Dictionary, Thesaurus, AntiThesaurus, Chargebook, VerbFrames, Conjunction, Negation, Morphology, Grammar. Each UtilityRow carries reference, original phrase, and a typed UtilityEffect. Both prepare population/version agreement and table validation precede lookups.

Prepared getters: `original`, `input_id`, `clauses`, `ast`, `draws_used`. Clause getters: `span`, `variants`. Action getters: `original`, `span`, `tokens`, `ast`, `captures`, `operators`, `spo`, `inhibited`, `uncertain_negation`, `conditional`, `unresolved_frame`, `executable`, `arithmetic_value`, `definitions`, `charges`, `origin`, `routes`, `complexity_token_count`.

Token getters: `source`, `lemma`, `span`, `kind`, `quoted`, `role`, `decimal`, `rule_refs`. Captures expose source/span/exact CanonicalDecimal; decimals expose coefficient:i128 and scale:u8. Signed decimal parsing is validated; unary arithmetic signs remain explicit ordered operator evidence. Captures are ordered lexical operands, rather than rounded results. Numeric words zero..ten normalize only within complete recognized arithmetic tails or explicit numeric frame objects. Non-numeric-frame ordinary number words and all quoted words remain text.

`SemanticAst` variants: Action(Vec<Token>), And, Or, But, IfThen, NegatedAction { uncertain, action }. Only immutable AST views come from validated actions. Downstream callers may clone these public descriptive enums, but cannot inject them into a Prepared result. Wrappers do not add lexical complexity except their explicit connective/negation operator. Action ASTs carry their condition antecedent; the complete Prepared AST joins original clause trees without duplicating consequent condition wrappers.

SPO slots are explicit `Resolved(String)` or `Unresolved`. A configured frame's missing required subject/object or invalid numeric object blocks execution; ordinary text without a declared required frame is retained with unresolved descriptive slots. No subject or object is invented. Origin retains input id, source clause/action ids, fanout id (0 for original), and substitution rule refs; each substituted token retains its source span/source bytes. Route hints expose lexical, arithmetic, conditional, inhibited, unresolved paths.

Scripts: `script::Registry::new(identity, revision, subsystems, declarations)`, `registry.capabilities(reads)`, `compile(source, scope, registry)`, `execute_script`, and guarded `execute_for_action`. CompiledScript, CapabilityLedger and EffectPlan fields are private and lack Deserialize. The exact six scope names reuse the existing bounded vocabulary: RelationalTriple, PatternBind, NodeAction, Vote, Orchestration, Reserved. Parent explicitly agreed. Reserved grants no calls; other calls need current declaration scope membership.

Registry handlers are Text, Concat, Math, Tape, LookUp, Bind. Literal args remain inert. LookUp accepts only a quoted registered subsystem literal and quoted key; unknown/dynamic/undeclared contacts refuse. Concat produces text when children are text/numbers and a typed Sequence otherwise, preserving ReadReference and Bytes evidence without inventing a lookup result. A Read effect is a pure requested contact, never actual host I/O. Bind computes/traces once per invocation, not durable idempotency. Plan getters expose typed value/effects/trace and registry identity/revision. Execution rechecks the complete immutable registry snapshot, including declarations and aliases, so same id/revision with altered content also refuses as stale. Contact preflight walks every nested call before evaluation; each child receives inherited capabilities intersected with its parent declaration. Math/tape/call/output budgets are aggregate per invocation. A failed later call exposes no partial plan or read effects.

## Bounded interpretations and limits

Per parent ruling, incomplete or nested natural-language `if` groups return Syntax. They are never flattened into executable ordinary actions. One complete conditional group per independent semicolon group is supported, with and/or/but expressions in its antecedent/body. IfThen binds the whole group, below those connectives. Context truth is attestation of the exact whole antecedent text, case-normalized; a supplied truth for only the last conjunct cannot authorize the whole condition. Unknown conditions remain Unresolved and unexecutable. Parent accepted this internal host contract. Expanding nested natural-language grammar needs new fixtures before production adoption.

The input ceiling counts characters, and spans count bytes. Fixed caps: 8000 input chars, 64 clauses, 16 variants/clause, 256 total variants, AST depth16, 4096 utility rows, 256 context tokens, 4096 host draws. Additional fixed preparation work ceiling: at most 4096 individual alternative opportunities per clause before sampling, else StepBudget; this avoids materializing a large repeated-match candidate product. Stochastic alternatives sample a weighted permutation of individual safe substitutions, not Cartesian combinations. Original is always included on success; all-zero weights yield original only. Every compatible positive-weight sense alternative stays explicit; if these alone exceed the per-clause cap, preparation refuses instead of silently discarding ambiguity. Per-clause stochastic sampling stops at its cap; exceeding a caller/global total cap returns VariantLimit.

Utility replacements cannot change quoted tokens, numbers/captures, operators, negation roles or their inhibition flags. The finite safe lexical vocabulary excludes built-in executable operators and number words; custom executable rule vocabulary is checked before substitution. Morphology only applies configured finite suffix replacements. Definition/charge entries are retained preparation evidence: charge evidence does not itself apply ATP, and consumers must honor action inhibition/conditional guards before treating it as an executable stimulus.

Exact decimal input checks include raw fractional scale<=18 and leading-zero-trimmed significant digit count<=18, then checked i128 parsing and trailing-zero canonical reduction. Arithmetic uses +,- precedence10, *,/,%20, unary+/-25 and right-associative ^30. Captured exact evidence stays separate from finite IEEE f64 computations.

This is an opt-in local API. Persistent resource-key insertion, text-v3 canonical framing, scanner scoring, routing/controller integration, real host effects, production credential authentication, general-language efficacy, held-out evaluation, save/schema migration, and production cutover are outside this task. No claim of legacy AST lossless adaptation or native/WASM parity execution is made here. Parent owns final all-four Studio gates and parity work.

## Review fix wave 1 (round 1/5)

Addressed all five Important findings and the arithmetic-exhaustion Minor from `language-task-review.md` in one wave. No public API shape changes or product expansion. This section supersedes the three pending review concerns above. Source is stable after final formatting, tests and Clippy; previous raw logs remain untouched.

RED first: `fix-1/red.log` records eight preparation and two script regression failures before implementation, reproducing every review counterexample. The focused RED command used `--no-fail-fast` so the failed preparation target did not prevent running the script counterexamples.

1. **Sequence results bypass the aggregate output ceiling.** Fixed by one recursive checked `value_bytes` measure applied to every produced Value, including Literal and arbitrarily nested Sequence nodes. Text counts UTF-8 bytes, Bytes counts payload bytes, Number counts eight bytes, ReadReference counts its subsystem/key bytes, and Sequence sums its children with checked addition. Container wrapping cannot erase a child's payload or charge the same carried child twice. Intermediate results and the complete emitted result must fit the invocation ceiling. `review_mixed_sequence_output_bytes_are_counted_recursively` first reproduced `Parent("hello",Tape("",""))` at output_bytes=1; it now refuses and succeeds at the exact five-byte bound. It also covers a nested mixed Sequence and Unicode text plus nonempty byte output at the exact aggregate boundary.

2. **A second `then` escapes the original conditional group.** Stray or duplicate Then now returns Syntax, including the exact `if rain then hello then calculate 2+2` escape and standalone `hello then calculate 2+2`. Semicolons remain the only independent-group boundary. Regression: `review_duplicate_then_cannot_escape_unresolved_condition`.

3. **Lexical rewrites can introduce executable safety vocabulary without any guard.** All rewrite paths now use the same validated tokenized vocabulary. The built-in negator predicate is shared between initial recognition and lexical safety and includes can't, dont and don’t. The private table-bound `validate_rewrite` checks the candidate's complete lexical tokens and registered Negation/Conjunction phrases, including matches crossing the changed-region boundaries with unchanged neighboring tokens. Existing semantic multiword lemmas are expanded into the check view, while quoted neighbors remain opaque. Dictionary and finite-morphology rewrites call the same guard before changing a lemma; thesaurus/sense replacements use its validated tokens. Built-in unsafe table outputs refuse during table validation; context-dependent/custom unsafe rewrites return UnsafeSubstitution with no Prepared result. Separate RED/GREEN regressions: `review_builtin_contraction_rewrites_refused`, `review_custom_multiword_rewrites_refused`, `review_dictionary_safety_introduction_refused`, `review_morphology_safety_introduction_refused`, plus `review_cross_boundary_safety_phrase_refused`.

4. **Required frames ignore already resolved grammar slots.** Required frames honor validated existing Subject/Object assignments before considering Other tokens as fallback candidates. Missing-slot checks therefore reflect the final assigned slots. `review_grammar_resolved_slots_satisfy_required_frame` reproduces Grammar alice->Subject, gift->Object plus required give frame, and now proves resolved alice/give/gift is executable with unresolved_frame=false.

5. **Multiword replacement source bytes no longer match their preserved source span.** Replacement token.source is now sliced directly from the preserved original action using the validated absolute source span converted to action-relative offsets. It is never reconstructed with whitespace joining. `review_multiword_replacements_preserve_exact_original_source_slice` asserts token.source equals the original byte slice for red-tab-fox, repeated spaces, and a Unicode multibyte phrase with repeated tabs.

The caller's budget remains valid. `review_exact_arithmetic_exhaustion_is_runtime_step_budget` first reproduced `Parent(Math("1"),Math("1"))` with arithmetic_steps=1 and now asserts StepBudget.
