## Real numbers and limits

The local host is Mac17,2, ten physical/logical CPU cores, 24 GiB RAM, macOS 27.2.
Five release-profile observations of the existing 500-vector, four-dimensional
HNSW workload produced median run-p50 values of **25.625 µs insert** and
**7.375 µs search**. All five runs, tail percentiles, process resource use,
source/binary hashes and reproduction commands are retained in the
[measurement report](2026-10-03-wdbx-release-measurements.md).
The shared host was not isolated; each run repeats one query 200 times and the
harness does not measure recall. These are local synthetic timing observations.
Durability, model quality, accelerator performance and production throughput
remain unmeasured by this workload. Earlier debug guard observations remain
separately labeled in the evidence JSON.
